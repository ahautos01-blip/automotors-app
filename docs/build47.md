# Build 47 — visible plans and personal chat organization

Version 1.0.3+47. Preserve the current App Store submission.

Home now features a single dark green/gold packs card immediately below search. Publicar always opens the plan catalogue first, including when free publication is available. Free publication remains a sticky visible action. The paid-plan callbacks and server-verified purchase/entitlement protections from build 46 are retained.

The inbox shows the latest visible message, local date/time and actual other participant’s public name. Search supports vehicle/name, accents and VW aliases. Personal pin/unpin and remove/restore actions are available per row and removal is also in the chat options menu. Removal requires a clear confirmation, offers Undo and a Deleted folder. It removes only the user’s inbox entry; messages and the other participant’s entry remain. A new message restores visibility. It does not block, suspend or erase an account.

The private preferences table has RLS and no client table grants. Narrow private functions verify a live active session and conversation participation; public wrappers are invokers. Reads still apply existing conversation/message RLS. The message-insert trigger only restores participant visibility. No arbitrary actor ID is accepted. Public profile enrichment never requests private user_profiles. Account changes discard pending results. Existing report/block controls and push dispatch are preserved.

SQL fixtures cover participant isolation, anonymous/outsider/revoked-session rejection, message RLS, unread counts, reversible deletion, new-message restoration, independent pins, and build-47 diagnostics/usage compatibility. Widget tests cover confirmation/cancellation/Undo/recovery/error, search/pins, Publicar routing, and Spanish/English/Catalan on a narrow screen at 200% text. No real messages, accounts, purchases or push notifications are generated by these tests.
